# 4. Amendment of Schedule to Act No. 16 of 1978
The Schedule to the Customs Tariff Act, 1978, being the External Tariff of the Republic of Sierra Leone, is amended as follows:-
(a) for cigarettes under H.S. Code 23402.20.00 the duty is 10%;
(b) for other tobacco products under H.S. Code 2402.90.00, the duty is 10%;
(c) for computers or word processing machines under H. S. Code 8469.11.00, the duty is 0%;
(d) for computer accessories under H.S. Code 8473.10.00 the duty is 0%;
(e) for rice (broken) under H.S. Code 1006.40.00, the duty is 10%.
(f) for wheat flour under H.S. Code 1106. 30.00 the duty is 10%;
(g) for sugar under H.S. Code 1701, the duty is 10%.
